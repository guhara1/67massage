`_build_*.py` 파일은 페이지를 생성한 **빌더 스크립트**입니다. 배포에는 필요 없으니
업로드 전에 삭제하셔도 되고, 추후 페이지를 더 찍어낼 때 재사용하셔도 됩니다.

## 3. 배포 방법

정적 파일이라 별도 서버 설정이 필요 없습니다. 아래 중 하나를 쓰면 됩니다.

- **Netlify / Vercel / Cloudflare Pages** — 폴더를 드래그&드롭하거나 Git 연결
- **GitHub Pages** — 레포에 올리고 Pages 활성화
- **일반 웹호스팅(cafe24 등)** — FTP 로 폴더 전체 업로드

> ⚠️ 반드시 HTTPS 로 서비스하세요. (구글 페이지 경험 기본 요건)

---

## 4. 배포 전에 꼭 바꿔야 할 것

1. **실제 도메인 교체**
   현재 모든 canonical·OG·sitemap·JSON-LD 의 도메인이
   `https://www.67massage.co.kr` 플레이스홀더로 들어가 있습니다.
   실제 도메인이 다르면 전체 파일에서 일괄 치환하세요.
   ```bash
   grep -rl "www.67massage.co.kr" . | xargs sed -i 's#www.67massage.co.kr#실제도메인#g'
   ```

2. **대표 이미지 교체**
   `assets/og-cover.jpg` 는 자동 생성한 임시 브랜드 이미지입니다.
   실제 촬영 이미지(1200×630)로 교체하면 검색·SNS 썸네일 품질이 올라갑니다.

3. **실제 사진 추가**
   현재는 텍스트·CSS 중심입니다. 공간/관리 장면의 **직접 촬영 사진**을 넣으면
   E-E-A-T 의 '경험(Experience)' 신호가 강해집니다. (타사·스톡 남용은 역효과)

4. **구글 서치콘솔 등록** 후 `sitemap.xml` 제출.

## 5. 적용된 SEO 요소 (요청하신 가이드라인 기준)

- **E-E-A-T / YMYL** — `about.html` 에 대표 바이라인(김유환), 회사·사업자 정보,
  편집 정책, 연락처를 명시. 건강 관련 글에는 의료 면책 문구 포함.
- **Who/How/Why** — 책임 저자·운영 경험 기반 서술을 회사소개에 명문화.
- **구조화 데이터(JSON-LD)** — 업종(HealthAndBeautyBusiness/DaySpa), WebSite,
  Article, Service, FAQPage, BreadcrumbList, ItemList, OfferCatalog 적용.
- **선호 이미지 지정** — schema.org 와 `og:image` 를 함께 지정(가이드 9번 항목).
- **페이지 경험** — 모바일 우선, 가벼운 정적 파일, 시스템 폰트/CDN, JS 최소화.
- **사이트 단위 품질** — 저품질 대량 양산을 피하고 페이지마다 고유 정보를 담음(아래 6번).

## 6. ⚠️ "지역명 포함 글 각 2개씩"에 대한 안내 (중요)

요청하신 항목 중 *"출장 가능 지역 이름을 포함해 각 2개씩"* 은
20개 지역 × 2 = **40개 글**을 의미합니다.

그런데 같은 내용을 지역명만 바꿔 40개를 찍어내면, **바로 그것이**
보내주신 가이드라인이 경고하는 두 가지에 정면으로 걸립니다.

> - 4번 스팸 정책: "검색 순위 조작을 위한 **대량 저가치 콘텐츠 양산**", "**도어웨이 페이지**"
> - 2번 도움되는 콘텐츠: "사이트 전체에 저품질 콘텐츠가 일정량 존재하면 **양질의 페이지까지 같이 순위가 떨어지는** 사이트 단위 신호"

즉, 무리하게 40개를 채우면 잘 만든 메인·서비스 페이지의 순위까지 끌어내릴 수 있습니다.
그래서 현재는 **검색에 안전하면서도 의도(지역 커버리지)는 달성**하도록 이렇게 구성했습니다.

- **지역 랜딩 20개** (`areas/`) — 각 지역마다 커버 동네·이용 특징·FAQ 를 다르게 작성
- **지역 가이드 아티클 3개** (`magazine/`: 수원·동탄·용인) — 길이 있는 고유 글 (나머지 지역의 **템플릿**)

### 나머지 지역 글을 안전하게 늘리는 체크리스트
지역 글을 추가할 때 아래 중 **최소 3개 이상**이 지역마다 실제로 달라야 합니다.

- [ ] 그 지역에서 실제로 받은 **이용 후기/사례** (가장 강력 — '경험' 신호)
- [ ] 지역 고유의 **세부 동네·랜드마크·생활 패턴** (예: 직장인 밀집 vs 신도시 주거)
- [ ] 지역별 **자주 받는 코스·시간대**의 차이
- [ ] 그 지역에서 **자주 묻는 질문**(중복 아닌 고유 Q)
- [ ] 접근/주차/방문 동선 등 **현장에서만 아는 정보**

### 권장 발행 계획 (한 번에 X, 주 2~3개씩 천천히)
나머지 17개 지역(오산·영통·수원역·인계동·구운동·궐동·처인구·수지·포곡·신갈·기흥·동백·미금역·수내역·정자역·서현역)에 대해
- 1차: **지역 가이드 아티클** 1개씩 (수원/동탄/용인 글을 템플릿으로, 위 체크리스트 충족)
- 2차: 실제 **이용 후기**가 쌓이면 매거진 `review`(이용 후기) 카테고리에 지역별 후기 글

> 매거진의 `review`(이용 후기) 카테고리는 지금 비워 두었습니다.
> 실제 고객 경험이 생기면 채우는 것이 '경험(Experience)' 신호에 가장 정확합니다.

원하시면 위 기준에 맞춰 **나머지 지역의 고유 가이드 글**을 추가로 작성해 드릴 수 있습니다.
(지역마다 다른 실제 정보를 알려주시면 품질이 훨씬 올라갑니다.)
